Lobster rclone

Lobster rclone is a private backup tool used only by its owner, Harry Randle of Quest Management Services Ltd. It is not offered to the public and no one else can sign in to it.

What it does

The app uses rclone, an open source file copying program, to copy the owner's own files from the owner's Dropbox account to the owner's own Google Drive. It runs on a single computer owned by the owner, on a nightly schedule.

It connects to one Google account only, the owner's, and uses the Google Drive API solely to write and check those backup copies. It does not read, use or collect information about anyone else.
