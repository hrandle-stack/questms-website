B / Where we come in

From the first cost plan to the last certificate

Before contract

Numbers an appraisal can stand on

Cost advice built from measured quantities and current market prices, with the assumptions written down. Then a contract set up so it can actually be run.

On site

Notices on time, every month

We value the work, issue the notices inside the contract timetable and keep one cost report that the client and the funder can both read across.

When it goes wrong

Accounts rebuilt, schemes finished

We have taken over jobs part way through, worked out what was built and what was paid, and put completion contracts in place. That work stays confidential.
